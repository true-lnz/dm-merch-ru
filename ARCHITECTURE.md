# Архитектура проекта (FSD + Next.js App Router)

## Базовая структура

- `src/app` — только файловый роутинг Next.js, layout и точка входа страниц.
- `src/views` — композиции для конкретных страниц (крупные page-блоки).
- `src/widgets` — крупные переиспользуемые блоки интерфейса (header, footer и т.д.).
- `src/features` — пользовательские сценарии (по мере появления интерактива).
- `src/entities` — бизнес-сущности и их UI/модели.
- `src/shared` — переиспользуемые примитивы: UI, config, lib, types.

## Правила зависимостей

Разрешено импортировать только из своего слоя или нижележащего:

`app -> views -> widgets -> features -> entities -> shared`

Обратные импорты запрещены.

## Публичный API

Каждый слайс экспортирует наружу только `index.ts`. Внешние слои импортируют
только из публичного API слайса, без deep-import по внутренним файлам.

## Роутинг

Роуты задаются только в `src/app/**/page.tsx`.
Компоненты и бизнес-логика не размещаются в роут-файлах напрямую, а подключаются
через FSD-слои.
